/free and open project management for everyone/

LucidPlan is a project management for teams of all sizes and jobs.

It's a flexible system made to simplify everyone's life, accessbile to all kinds of users.

If you like my work, please support me by [[https://bmc.link/jjbigorra][buying me a cup of coffee ☕]] so I can continue with a lot of motivation.


LucidPlan enhances the use of Agile work methodologies in teams due to its fast-paced no nonesense-workflows and customizability, also thanks to being written in Lisp.

This tool is the fruit of years of experience using bloated proprietary systems like Jira/Trello, and experiencing the insane frustrations they bring.

Visit my instance of LucidPlan here:
https://lucidplan.jointhefreeworld.org/

Built with [[https://www.gnu.org/software/guile/][Guile Scheme]] and [[https://artanis.dev/][GNU Artanis]], [[https://sqlite.org/][SQLite]], [[https://codeberg.org/jjba23/olive-css][Olive CSS]]

LucidPlan provides a comprehensive suite of tools to keep your projects organized:

- *Multi-Project Workspaces*: Easily manage dozens of repositories or projects from a single unified dashboard. Features a quick-access "go to" dropdown and search functionality to navigate between contexts instantly.
- *Versatile Backlog Management*: View all your project tasks in a clean, list-based backlog. Tickets have different types (e.g., task), statuses (e.g., todo), org-mode syntax descriptions with links and rich content, and easy editing/deletion.
- *Kanban Boards*: Visualize your workflow with built-in Kanban boards. Effortlessly track tickets as they move through columns like =To-do=, =Work in Progress=, and =In Review=.
- *Clean and Distraction-Free UI*: A minimalist and accessible interface built with [[https://codeberg.org/jjba23/olive-css][Olive CSS]], featuring global search, quick project creation, and a toggleable light/dark mode to suit your preferences.
- *Granular User Management*: Add, edit, and manage team members with ease. Permissions are handled using native Lisp lists (e.g., =`(lucidplan:ticket-create lucidplan:project-delete)=), allowing for incredibly fine-grained, programmatic access control, effectively providing an easy to use ACL with which you can control exactly what each user can/cannot do.
- *Fully Customizable:* Hack the behavior and content of everything with simple Lisp (Scheme) code.
- *Cross-platform:* Runs anywhere that Guile Scheme can run, and exposes web endpoints, and is thus accessible from computers, phones, etc.
- *Free Software*: Contribute to its development or extend it with your own custom features.

This project adheres to the [[https://jointhefreeworld.org/blog/articles/personal/jointhefreeworld-ai-policy/index.html][jointhefreeworld AI (Artificial Intelligence) policy]].

Our core principle is simple: *AI should assist human creativity and problem-solving, never replace human reasoning.*

While tools like Large Language Models (LLMs) and interactive chatbots can be beneficial for reviewing, refactoring small functions, or acting as a sounding board, they should be used with moderation.

We require a human in the loop for all contributions. The use of autonomous AI agents to automatically generate and submit pull requests to this project is strictly prohibited.

* On Reproducibility, and Why GNU Guix? 🐂️

A build should never fail because "it works on my machine." Software must aim to be transparent, fluid, powerful, and extensible, and for this, reproducibility is essential.

With [[https://guix.gnu.org/][GNU Guix]], you get:

- 🧠 *Infinite Expressiveness:* [[https://www.gnu.org/software/guile/][Guile Scheme]] provides total, unconstrained control over packages and build definitions.
- 🎯 *Bit-Identical Environments:* Every dependency graph is declarative, immutable, and functionally derived.
- ⏳ *Time Travel:* Recreate the exact system state from months or years ago using ~guix time-machine~.
- ✨ *No Hidden State:* Build artifacts are pure functions of their inputs—zero implicit system dependencies.
- 🔍 *Total Inspectability:* Easily inspect, modify, and patch any point in the build graph.

Far from rigid, absolute reproducibility empowers fearless experimentation:

- *Declarative Shells:* Instantly spin up isolated environments:
  #+BEGIN_SRC sh
  guix shell -m manifest.scm
  #+END_SRC
- 🔄 *Transactional Upgrades & Rollbacks:* Experiment freely. If an update breaks, rollbacks are atomic and instantaneous.
- *Unified Tooling:* One tool seamlessly handles dev shells, containers, system configs, and package builds.
