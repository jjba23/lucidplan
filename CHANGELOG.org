/free and open project management for everyone/

LucidPlan is a project management for teams of all sizes and jobs.

It's a flexible system made to simplify everyone's life, accessbile to all kinds of users.

If you like my work, please support me by [[https://bmc.link/jjbigorra][buying me a cup of coffee ☕]] so I can continue with a lot of motivation.

---------------------------

You can run migrations on your SQLite database with the following, or any other way you choose:
#+begin_src sh
sqlite3 database.db "INSERT INTO table VALUES (something)"
#+end_src

----------------------------------

* v0.6.4

Removed constraint of uniqueness in ticket titles, this might require some manual touches on the database ~ticket~ table.


* v0.6.0

Added ~priority~ column to ~ticket~ table. Added possibilities to sort tickets in the backlog by priority.

Migration will be needed:
#+begin_src sql
ALTER TABLE ticket ADD COLUMN priority INTEGER;
#+end_src
